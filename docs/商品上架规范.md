# AI 超市商品上架规范

开发者通过入驻审核后，在开发者中心创建应用客户端，填写商品名称和一句话简介，再展开「上架申请」。每个商品选择一种主要交付格式。现阶段以外部 HTTPS 入口交付，卖家自行维护服务和文件。

| 格式 | 交付入口 | 专项说明 |
| --- | --- | --- |
| 网页应用 | 应用启动页 | 列出支持的设备和浏览器、是否需要注册、首次使用步骤及成功结果。 |
| API 服务 | 接入文档或控制台 | 给出认证方式、请求与响应示例、限流、错误处理和领取凭据的流程。示例中使用占位凭据。 |
| 数字资源 | 下载或领取页 | 列出文件名、格式、大小、版本、所需软件和导入方法。模板、提示词包和工作流适用此类。 |

## 卖家填写模板

1. **交付内容和版本**。列出买家能取得的功能或文件，注明版本和更新权益。
2. **使用步骤和条件**。从领取写到第一次成功使用，写明设备、账号、依赖和地区限制。
3. **价格和限制**。一次性开通使用非负整数积分，免费填 0。列出配额、有效期、上游费用及承担方。
4. **数据处理**。说明采集字段、用途、第三方接收方、保留期限及申请删除的途径。
5. **授权范围**。说明个人使用、团队使用、商用、修改及再分发的条件，确认对代码、模型和素材均有相应分发权。
6. **售后**。填写可用的联系方式、响应时限、故障处理、退款条件和申请步骤。公开说明中使用业务联系方式。
7. **交付地址**。提供稳定的 HTTPS 入口。卖家在自己的服务中控制最终文件和账号权限。共享链接可能被转发，请勿填写永久密钥或个人登录信息。

## 审核和变更

审核员核对商品描述与实际交付是否一致，按说明走通一次领取和使用，核对标价、额外成本、授权声明和售后渠道。涉及第三方品牌或素材时，可要求补交授权材料。无法复现或说明缺失时，填写具体退回原因。卖家在原申请处修改后重新提交。

填写时可以点击「保存草稿」，再登录同一卖家账号继续。每款商品同时只接受一个待审核版本。已上架商品重新提交时，旧报价继续生效，审核通过后替换。审核备注仅向提交者和审核员开放，生产站启用 HTTPS 后可填写。

新购买记录保存下单时的版本说明、价格、授权、售后条款和交付入口。买家可在「个人中心 → 账单与售后」领取购买的版本，正常下架后仍可领取。请为各版本提供长期有效的独立交付地址。若卖家覆盖外部链接指向的文件，平台无法恢复原文件。升级前已有的记录可能没有成交快照。
